# Стиль Reels «как ИнвестСканер» (эталон v06, 2026-08-23)

Этот скилл дополняет `reel-turnkey`: процесс (транскрипция → мастер → пакет →
утверждение → рендер) идёт по нему, а ЗДЕСЬ зафиксировано, КАК должен выглядеть
и звучать сам монтаж. Эталонный проект:
`projects/2026.08.22_ii-razobral-16-investproektov` (мастер v06 + `previews/v06-preview-music.mp4`).
Обязательные общие правила — `memory/feedback_reels-editing.md`; при конфликте
побеждает более поздняя запись.

## Шрифты (строго)

- КАПС: **Montserrat** Variable weight 500, вразрядку (letter-spacing 6–9 px), белый.
  @font-face с файла `brand-ii-business/fonts/Montserrat-Variable.ttf` работает.
- Прописной акцент: **системный шрифт `Pushkin`** — писать `font-family: 'Pushkin', cursive`
  БЕЗ @font-face (файл Pushkin.ttf браузер отвергает; системное имя работает).
  Оранжевый #FF751F, крупно (≥100 px), утолщение `-webkit-text-stroke: 1.4–1.8px #FF751F`.
  Monotype Corsiva и fallback-курсивы ЗАПРЕЩЕНЫ — пользователь отличает и бракует.
- Заголовки мокапов: **Bebas Neue Cyrillic** капсом, ключевое слово оранжевым.
- Субтитры: Montserrat Bold 48 капс (ASS), ключевые слова оранжевым `&H1F75FF&`.

## Хук (первые ~4 секунды)

- Компактная тёмная плашка (rgba(8,12,24,.58), radius 30) на УРОВНЕ ГРУДИ
  (overlay y≈1060), ЛИЦО ПОЛНОСТЬЮ ОТКРЫТО — без тинта, без размытия кадра, без часов.
- ≤4 строк: 2 капс-строки + 1–2 прописных Pushkin. Текст — формула
  [что произошло]+[неожиданный исход], цифры только подтверждённые.
- Печать по буквам: CHAR 0.022 c, GAP 0.12 c, курсор-палочка; старт 0.35 c,
  фейд-аут ~3.85–4.2 c. Шаблон: `templates/type-hook.html` (авто-подгонка ширины строк
  и плашки уже внутри), рендер PNG-секвенции — `templates/render-type.js`.
- ЗВУК ПЕЧАТИ НЕ ДОБАВЛЯТЬ: синтетические клики пользователь дважды забраковала.
  Добавлять только если она пришлёт живую запись своей клавиатуры.

## Финальная заставка (4.5 c)

- Полноэкранный градиент #3a4560→#141c33 + констелляция (точки и линии), БЕЗ циферблата.
- Главный призыв — оранжевая плашка «ПОДПИШИСЬ» (самый крупный элемент), затем
  Pushkin-строки «и следи за …» и капс-строки контекста. Печать CHAR 0.025.
- Вход заставки — zoom-in (zoompan 1.12→1 за 9 кадров) + вспышка.
- Шаблон: `templates/type-final.html`. Кодовые слова воронки — только по явному запросу.

## Переходы (на каждой склейке, на КОМПОЗИТЕ)

Эффекты на базовом слое под непрозрачной вставкой не видны — переходы накладывать
ПОСЛЕ всех overlay (canonical-граф в `templates/build-master.py`):

- **whip**: рывок композита по X `150*sin(2π(t−T)/0.22)` поверх размытой копии
  (split → boxblur 24 → overlay x=whip) + boxblur 26 на ±0.10 c;
- **flash**: `eq=brightness=0.34:saturation=1.15` на 0.10 c;
- **glitch**: `rgbashift=rh=-22:bh=22:rv=6:bv=-6` на ±0.07 c;
- **slide-in слева** для перебивок (overlay x от −1080, ease-out 0.28 c);
- **push справа + уход влево** для мокапов (overlay x от +1080 за 0.30 c, выход −1080 за 0.25 c);
- **zoom-in** для вставок выступления/мокапов/заставки (zoompan 1.25–1.3→1 за 10 кадров);
- punch-зум ±0.13 на базовых склейках; типы чередовать, не повторять подряд.
- SFX за 0.12 c до склейки: whip→whoosh −16 дБ, flash→click −13, glitch→pop −13,
  лёгкая вариация pitch (±5–10 %). Файлы: `projects/2026.08.13_instruktsiya-ii-montazher-pravki/assets/sfx/`.

## Зум-планы говорящей головы

Чередование широкий 1.00–1.06 / крупный 1.13–1.20 со сдвигом кадра xk ±0.25–0.32
(«вторая камера»), смена на границах фраз; кроп якорить на лицо (FACE_Y по кадру).
Речь целиком, ускорение ×1.15. Вставки чужих съёмок (720×1280) — lanczos-апскейл
до 1080×1920 + eq (brightness +0.03–0.04, contrast 1.06–1.08, saturation 1.08–1.10);
громкость речи вставки выравнивать с основной (замер ebur128, цель ±1 LUFS).

## Субтитры

ASS через libass, впекать в мастер (генератор — `gen_subs` в `templates/gen-subs-and-keys.py`):
Montserrat 48 капс, белый, обводка 4, тень 3, полупрозрачная подложка BackColour &H8C000000,
MarginV 300 (над ник-бейджем), по 3 слова, стык реплик без дыр (<0.6 c), ключевые
слова оранжевым. Слой субтитров — ПОВЕРХ хук-оверлея. `fontsdir=brand-ii-business/fonts`.

## Мокапы приложений / скринов

Тёмный градиент #101a33→#0a0f1c, Bebas-заголовок 84 (ключевое слово оранжевым),
оранжевые/зелёные Bebas-чипы-теги, РЕАЛЬНЫЕ скрины крупно (карточки ≤2 на экран,
смена карточек каждые ~2 c, transition opacity+translateY 0.32 c), по широким слайдам —
zoom-pan к баллу/вердикту/колонке (текст в кадре ≥33 px). Низ ≤1450 (зона субтитров).
Баллы чужих проектов показывать только высокие/согласованные. Шаблоны:
`templates/mock-cards.html`, `templates/mock-slides.html`, запись — `templates/record-mock.js`.

## Звук

- Голос: highpass 100, afftdn −23, dynaudnorm, EQ (250 −2.5 / 1800 +1.5 / 2900 +4 / 4800 +2.5),
  deesser, компрессор 2:1, alimiter, atempo 1.15.
- Музыка: трек ВЫБИРАЕТ ПОЛЬЗОВАТЕЛЬ (эталон — style-02-chill-deephouse из `Музыка/`),
  зациклить acrossfade d=2, gain −12 дБ, sidechain-ducking threshold −28 дБ ratio 6
  attack 12 release 400, fade-in 0.4 / fade-out 1.8. Синтез-биты движка не предлагать.
- Финальный проход: `loudnorm=I=-11.5:TP=-1.2:LRA=9`.

## Прочее

- Ник-бейдж `@XENIIA_NEURO` (аватар в оранжевом кольце) — overlay y=1680 на всём
  ролике до финальной заставки (`templates/nick-badge.html`).
- Мастер кодировать ALL-INTRA: `-g 1 -bf 0 -crf 17 -fps_mode cfr -video_track_timescale 90000`.
- Превью пользователю отдавать СРАЗУ с субтитрами и музыкой (после первого мастера) —
  голый мастер без субтитров вызывает правки «где субтитры/переходы».
- `render-type.js` ищет HTML относительно СВОЕЙ папки — копировать шаблоны и скрипт
  в рабочий scratchpad вместе.

## Чек-лист выдачи (сверх QA reel-turnkey)

1. Pushkin-строки — каллиграфия (не округлый fallback)? Кегль ≥70 px?
2. Переход виден на КАЖДОЙ границе вставки (проверить стоп-кадрами на ±0.1 c)?
3. Субтитры есть на вставках и НЕ притушены оверлеями?
4. Лицо не перекрыто ни хуком, ни плашками ни в одном плане?
5. Часов нет ни на хуке, ни на заставке; звука печати нет.
6. Музыка = присланный пользователем трек (сверить имя файла), в паузах ≥10 дБ ниже речи.
