# Монтаж рилсов @xeniia_neuro

Всё делается локально через ffmpeg и PIL. Облачный монтаж (Virale) не нужен
и не используется — расшифровка своя и бесплатная.

## Где что лежит

| | |
|---|---|
| `brand/brandbook.md` | правила оформления и все наработанные ограничения. **Читать перед сборкой** |
| `brand/xeniia-reel-style.SKILL.md` | исходная спецификация стиля от пользователя (эталон «ИнвестСканер») |
| `brand/theme.json` | палитра и шрифты |
| `brand/fonts/Pushkin.ttf` | каллиграфия для хука и заставки |
| `tools/` | сборщики: расшифровка, нарезка, хук, вставки, субтитры, CTA, эффекты |
| `reels/` | разбор каждого ролика: тайминги, решения, грабли |

При конфликте брендбука и исходной спецификации побеждает брендбук —
в нём записаны более поздние правки пользователя.

## Порядок сборки

1. **Расшифровка.** `python3 tools/asr_ru.py <audio.wav> <words.json>` —
   sherpa-onnx + GigaAM v2, отдаёт слова с таймкодами. Модель тянется из
   релизов GitHub (`k2-fsa/sherpa-onnx`, тег `asr-models`); хосты Whisper,
   Vosk и Silero закрыты политикой egress.
2. **Где лицо.** `python3 tools/face_scan.py <src>` — чтобы зумы и подложки
   его не резали.
3. **Нарезка.** Зум-планы на границах фраз, широкий чередуется с крупным.
   Речь **целиком**, темп ×1.15. Тряски нет.
4. **Хук**, **вставки**, **субтитры**, **плашка кодового слова**, **заставка** —
   PNG-секвенции, накладываются оверлеями.
5. **Звук.** Цепочка голоса из брендбука, музыка пользователя с ducking,
   финальный `loudnorm=I=-11.5:TP=-1.2:LRA=9`.
6. **Переходы** — на композит, после всех оверлеев.
7. Сверить с чек-листом брендбука, отдать файл, записать разбор в `reels/`.

## Никогда

- **Не резать слова.** Речь идёт целиком, пользователь забраковала обрезку дважды.
- **Не добавлять звук печати и щелчки.** Синтетические клики забракованы дважды.
  Вуши и низкие удары на склейках — можно (`tools/build_sfx.py`).
- **Не закрывать лицо.** Вставка либо на весь экран, либо внизу. Подложка хука —
  ниже лица.
- **Не подменять Pushkin** другим курсивом. Fallback-курсивы запрещены прямым
  пунктом спецификации.
- **Не рисовать поддельные скриншоты** чужих продуктов. Только честные схемы
  или настоящие данные (например, автоворонки из Chatplace).
- **Не трясти кадр.** Punch-зум и вспышка — да, постоянная тряска — нет.

## Грабли, на которые уже наступали

- `ImageDraw` с RGBA-заливкой **заменяет** альфу, а не смешивает: полупрозрачные
  фигуры и тени рисовать отдельным слоем и класть через `Image.alpha_composite`.
- `acrossfade` через `asplit` ломает длину музыки — подавать один и тот же файл
  двумя отдельными входами.
- Трек может кончаться раньше ролика: проверять `silencedetect` и зацикливать.
- У Pushkin высокие росчерки: строки ставить по боксу чернил, зазор
  положительный, кегль не ниже 100 px.
- `alimiter` без `level=disabled` сам выравнивает уровень.
- После `crop` нужен `setsar=1`, иначе `concat` откажется склеивать.
