# Мой_ИИ — бэкап контекста Claude

Всё, что Claude знает обо мне и умеет для меня, в обычных файлах. Переезжает в любую нейросеть за вечер.

```
Мой_ИИ/
  память.md                         ← кто я и мои правила (загружать первым)
  промпты.md                        ← повторяющиеся запросы
  проекты/
    контент/инструкция.md           ← Project instructions для проекта «Контент»
    контент/база_знаний/            ← брендбук, theme.json + файлы проекта
    продажи/инструкция.md           ← Project instructions для проекта «Продажи»
  скиллы/
    kontent-ksenii/ + .zip          ← тексты и карусели в моём стиле
    chatplace-voronka/ + .zip       ← воронки с проверкой подписки
    montazh-reels/ + .zip           ← монтаж рилсов (Claude Code)
    xeniia-reel-style/ + .zip       ← эталон стиля «ИнвестСканер»
```

## Чек-лист: что сделать руками

Эти шаги делаются только из вашего аккаунта, за вас их не нажать.

- [ ] **1. Архив.** С компьютера: Settings → Privacy → Export data → Export.
      Ссылка придёт на kseniapikus35@gmail.com и живёт 24 часа — скачайте сразу,
      положите ZIP рядом с этой папкой (в git его не кладите: там вся переписка).
- [ ] **2. Память.** Settings → Capabilities → «Посмотреть и изменить память».
      Сравните с `память.md`, недостающее допишите в файл.
- [ ] **3. Проекты.** Откройте каждый проект в Claude, сверьте Project instructions с
      `проекты/*/инструкция.md`, файлы базы знаний скачайте в `база_знаний/`.
      Есть ещё проекты — заведите для каждого папку по тому же образцу.
- [ ] **4. Скиллы.** Settings → Capabilities → Upload skill → `скиллы/kontent-ksenii.zip`
      и `скиллы/chatplace-voronka.zip`. Папки не удаляйте — это исходники.
      В Claude Code те же папки кладутся в `~/.claude/skills/`.
- [ ] **5. Правило 3–2–1.**
      - копия 1 — эта папка в приватном GitHub-репозитории (уже лежит здесь);
      - копия 2 — `git clone` на компьютер;
      - копия 3 — флешка или внешний диск, раз в месяц.
      Проверьте, что репозиторий **приватный**: GitHub → Settings → General → Danger Zone → Change visibility.

## Правило обновления

Меняете инструкцию или правило — сначала в файле здесь, потом в Claude. Файл главный.
