# Монтаж рилсов — @xeniia_neuro

Репозиторий с брендбуком и разборами смонтированных рилсов для аккаунта
[Ксения Пикус | НЕЙРОСЕТИ ДЛЯ БИЗНЕСА](https://www.instagram.com/xeniia_neuro/).

## Структура

- [`brand/theme.json`](brand/theme.json) — фирменные токены: палитра, шрифты, скругления, тени.
  Источник истины, взят из локального пайплайна «Автомонтаж».
- [`brand/brandbook.md`](brand/brandbook.md) — тон, формат, правила титров, требования к съёмке.
  Фирменный стиль — из `theme.json`; правила хронометража и хуков — из данных аккаунта
  и нишевой аналитики Virale, цифры внутри.
- `tools/` — сборщик карточки хука, генератор звука карандаша,
  сборщики планов, плашек и звука по роликам
  (`build_reel_*.py`, `build_cta_*.py`, `mix_reel_*.py`).
- `reels/` — по файлу на ролик: расшифровка исходника, решения по монтажу,
  параметры запуска и готовая подпись к публикации.

## Как собирается ролик

1. Речь расшифровывается локально — `tools/asr_ru.py` (sherpa-onnx + GigaAM v2).
   Отдаёт слова с таймкодами, из них строятся субтитры и границы фраз.
2. `tools/face_scan.py` показывает, где в кадре лицо, чтобы зумы и плашки его не резали.
3. Из брендбука берутся хронометраж, пресет титров и кодовое слово CTA.
4. Хук, вставки, субтитры, плашка CTA и заставка собираются PNG-секвенциями
   и накладываются на нарезку через ffmpeg. Речь не режется.
5. Готовый мастер сверяется с чек-листом скилла: лицо открыто, переходы видны,
   субтитры читаемы, музыка — присланный трек и ниже речи.

Облачный монтаж через Virale больше не нужен: расшифровка локальная и бесплатная.
