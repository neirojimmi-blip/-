# Карусели Ксении Пикус

Источник правды по цвету и шрифтам — `brand/theme.json` и `brand/brandbook.md`.
Голос и структура — скилл `kontent-ksenii`. Этот скилл фиксирует сборку
готовых PNG, а не только текст.

## Когда

Пользователь просит карусель, слайды, карточки поста. Тема может прийти
как `[тема]` или остаться пустой — тогда берём боль команды собственника
про ИИ и закрываем курсом / внедрением с обучением.

## Формат

- **9 слайдов**, каждый отдельный PNG.
- Размер **1080×1350** (4:5, лента Instagram).
- Слайд 1 — хук. Слайды 2–7 — проблема и шаги. Слайд 8 — два пути.
  Слайд 9 — приглашение: курсы **или** разработка с ИИ с обучением команды.
- Кодовые слова в финале: `КУРС` (программа школы) и `КОМАНДА` (под ключ
  + обучение сотрудников). Не шаблонные вопросы вроде «А вы из каких?».

## Фирменный стиль

| | |
|---|---|
| Фон | `#2E4078` |
| Панель | `#3A4C8E` |
| Линия | `#46589E` |
| Карточка | `#FFFFFF` / `#F2F5FB` |
| Акцент | `#FF751F` — только акцент, не заливка слайда целиком кроме CTA-плашки |
| Текст | `#2E4078` по белому, белый по синему |
| Вторичный | `#5A6A9A` |
| Скругление | 24 |
| Тень | `0 20px 50px rgba(23, 33, 64, 0.35)` |
| Рамка | `2px solid rgba(46, 64, 120, 0.12)` на карточках; на синем — белая 12% |
| Декор | плюсы и рамка. Орбиты, звёзды, стрелки, зерно, свечение — нет |

### Шрифты

- **Bebas Neue Cyrillic** — заголовки, капс, до 5 слов.
- **Montserrat** Medium/SemiBold — 1–2 строки тела, крупно (кегль ≥36).
- **Pushkin** — рукописный акцент, **одно слово на слайд**, кегль ≥100 на
  обложке и CTA, ≥72 на внутренних. Без обводки, которая утолщает штрих.
  Fallback-курсивы запрещены.

Текст не мельчить: подписчики жалуются на мелкий.

## Голос

Сложное — простым языком. Без канцелярита и пустых слов. Не писать
«выдаёт воду». Заголовок цепляет, но не пугает.

## Фото

На каждом слайде своё фото Ксении, текст не закрывает лицо. Если живых
кадров нет в репозитории — отдаём графические слайды (они должны выглядеть
готовыми) и в `copy.md` пишем, какое фото поставить на каждый слайд.
Не подставлять чужие и сгенерированные лица вместо её фото.

## Сборка

```
python3 tools/build_carousel.py carousels/<папка>
```

В папке: `slides.json` (тексты), на выходе `01.png`…`09.png`, `preview.png`,
`copy.md` (таблица + подпись к публикации).

Чек-лист перед выдачей: кириллица в Bebas не падает в тофу; Pushkin — та
самая каллиграфия; оранжевый только акцент; на CTA есть курсы **и**
разработка с обучением команды.
