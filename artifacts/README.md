# Артефакты для вставок

Всё здесь создано на самом деле, а не нарисовано макетом. Скилл требует
реальные скрины, поэтому вставки собраны из настоящих файлов и настоящей сессии браузера.

| Файл | Что это | Как снят |
|---|---|---|
| `finmodel.xlsx` | Финмодель школы на 12 месяцев с формулами `=ROUND(лиды*конверсия/100,0)`, выручкой и прибылью | LibreOffice Calc посчитал формулы и отдал PDF, дальше `pdftoppm` в PNG |
| `deck.pptx` | Слайд «Школа ИИ для бизнеса» в фирменной палитре | LibreOffice Impress → PDF → PNG |
| `form.html` | Форма заявки на курс | Playwright открыл её в Chromium и **реально заполнил**: имя, телефон, город, формат, задача, затем нажал отправку. Снят результат с подтверждением |
| — | Раскадровка монтажа | Шесть кадров из самого ролика плюс дорожка из 50 субтитров, построенная по `subs4.ass` |

Чего здесь нет: скрина настроек памяти Claude. Он приходил вставленной в чат
картинкой, а такие изображения не сохраняются файлом на диск — нужен вложенный `.png`.
Перерисовывать интерфейс по памяти нельзя: это была бы подделка вместо настоящего снимка.
