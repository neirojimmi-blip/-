# Воронка ЧЕРТЕЖ

Кодовое слово: **ЧЕРТЕЖ**.

Почему не КАД и не ИНСТРУКЦИЯ. КАД читается как аббревиатура и путается с CAD. ИНСТРУКЦИЯ, КУРС, МОНТАЖ, АГЕНТ, ДЕСКТОП уже стоят на других постах. ЧЕРТЕЖ — одно русское слово из темы, как ДЕСКТОП в том рилсе. Частичное совпадение ловит «чертёж» и «чертежи».

Наполнение не «вот ссылка на канал». В Direct уходит сам разбор. Канал — за готовыми промптами.

Путь: комментарий ЧЕРТЕЖ → кнопка в Direct → разбор в Direct → промпты в [t.me/xeniia_neuro](https://t.me/xeniia_neuro) → при желании КУРС / ВНЕДРЕНИЕ боту.

## Собрать в ChatPlace

1. Пост в канал из `telegram-post.md`. Закрепить.
2. Карусель в Instagram. Подпись из `carousels/2026-11-07-autocad-ii/copy.md`.
3. Автоматизация `ЧЕРТЕЖ · разбор в Direct → канал`, аккаунт Instagram @xeniia_neuro.
4. Триггер: только комментарий, этот пост, слово `ЧЕРТЕЖ`, частичное совпадение.
5. Автоответы — `comment_replies` из `scenario.json`.
6. Сообщение 1: текст `dm1`, кнопка действия «ОТКРЫТЬ РАЗБОР». Без ссылок.
7. Сообщение 2: текст `dm2` — сам разбор. Кнопка-ссылка «ПРОМПТЫ В КАНАЛЕ».
8. Сообщение 3: курс / внедрение, кнопка на @pikus_ai_bot.
9. Включить. Чужие воронки не трогать.

Cursor: `funnels/chertezh/cursor-mcp.json.example`. Ключ — ChatPlace → Настройки → MCP. Без ключа в этой среде автоматизация в аккаунт не создаётся.
